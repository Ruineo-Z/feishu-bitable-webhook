## Why

当前工作流页面虽然已经进入可视化方向，但核心编辑体验仍不够“业务友好”：节点配置入口分散、选中态不明确、节点类型选择不成体系，导致业务人员在搭建流程时效率低、理解成本高。现在字段编解码链路已验证跑通，正是收口为“节点中心配置体验”的最佳时机。

## What Changes

- 将工作流编辑器重构为“左侧列表 + 中间画布 + 节点选中后右侧配置面板”的三段式体验。
- 新增节点类型选择入口（点击 `+` 后展示可添加节点种类），明确触发器/条件/动作/结束等分类。
- 将节点配置改为“按节点类型动态渲染”的表单模式（不同节点展示不同配置项）。
- 中间画布支持拖拽、平移、缩放等基础导航能力，保障复杂流程可读可编排。
- 强化条件节点的 if/else 分支表达与连线可读性，确保流程路径清晰。
- 统一采用 Shadcn 风格组件语义构建配置界面，提升视觉一致性与实现效率。

## Capabilities

### New Capabilities

- `workflow-node-centric-builder`: 提供以节点为中心的工作流编排体验，支持节点选择、节点类型添加、按类型动态配置。
- `workflow-canvas-navigation`: 提供画布级交互能力，包括节点拖拽、画布平移、缩放与复杂流程可视导航。

### Modified Capabilities

- `workflow-management-web-ui`: 将现有工作流管理 UI 的编辑体验升级为节点化配置工作台，保留与现有 API 契约兼容。

## Impact

- 影响代码：主要在 `web/workflow-studio/**` 的页面结构、画布交互、节点面板与表单渲染逻辑。
- 影响前端依赖：继续使用并扩展 Shadcn 组件能力（必要时补充相关组件安装）。
- 影响接口：不新增后端 API，沿用现有 workflow 管理与保存接口。
- 影响交付：需要补充节点类型与配置 schema 的产品清单，以支持后续逐节点实现与验收。
